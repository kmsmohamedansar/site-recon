# Responsible reproduction

Website behavior and techniques can be studied from the public browser surface. That does not automatically grant permission to republish someone else's code, copy, brand, artwork, photography, custom illustrations, or a highly distinctive page wholesale.

Use these defaults:

- Recreate techniques with new code instead of de-minifying and republishing bundles.
- Replace brand identifiers and authored content.
- Use the site's measurements as observations, not as a license to duplicate the complete composition.
- Check the repository or asset license before direct reuse. Preserve attribution and notices required by that license.
- Treat source maps, private APIs, authenticated routes, and unpublished assets as out of scope unless the owner explicitly supplies or authorizes them.
- Do not bypass paywalls, authentication, bot protection, CSP, browser warnings, or rate limits.
- Do not send forms, create accounts, or trigger purchases while studying interactions.
- Keep request volume modest and honor obvious operational limits.

For a user-owned site, it is reasonable to reuse their own source and assets. Still distinguish deployed code from experiments or dead dependencies so the report remains accurate.
