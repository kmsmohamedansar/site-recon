# Security and responsible reporting

Only inspect sites you are authorized to access, and respect the target's terms and any applicable testing scope. This tool observes the public browser surface; it is not an authorization to probe private systems or bypass access controls.

Reports and artifacts can contain page content, URLs, public assets, screenshots, and short bundle excerpts. Review and remove sensitive or copyrighted material before sharing them. Avoid including live credentials or personal data in public issues.

To report a vulnerability in Site Recon itself, use GitHub's private vulnerability reporting for this repository if available, or contact the repository owner privately. Include a minimal synthetic reproduction and avoid testing third-party systems without permission.
